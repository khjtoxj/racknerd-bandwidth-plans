## 什么是大带宽服务器：带宽、流量、独享是三件事

大带宽服务器指端口带宽达到100Mbps及以上的服务器，业内普遍以100M作为“大带宽”的门槛，常见机型支持100M和1000M网卡自动切换。带宽衡量的是单位时间内最多能传多少数据，100Mbps换算成下载速度是100÷8=12.5MB/s——这是理论峰值，实际速度会受线路、时段和对端服务器影响。

流量是另一个维度。带宽像水管粗细，流量像每个月总共能放多少水。端口再大，月流量配额耗尽后照样停摆，所以选机器要同时看两个数：端口多大、每月给几TB流量。

第三个容易被忽略的是独享和共享。不少标着“100M大带宽”的便宜机器，实际是很多用户共享一条总管道，晚高峰大家一起挤，标称速度只剩零头；独享带宽才是这条线专供你一台机器。差价主要就差在这里，租之前务必问清楚。

## 常见问题

**100Mbps带宽的实际下载速度是多少？**

理论值12.5MB/s（100Mbps÷8）。实际受线路和时段影响，能稳定跑到8-10MB/s就算不错的线路。

**月流量1TB是什么概念？**

平均每天约33GB。换个角度算，1Gbps端口满速跑一小时大约消耗450GB流量，也就是说1TB配额只够满速传输两个多小时。大端口不等于能随便用，流量才是真正的天花板。对个人网站、备份、轻量中转来说1TB很宽裕，做公共下载站就明显不够。

**RackNerd 到国内的速度怎么样？**

普通国际线路，走163骨干网，电信和联通晚高峰波动比较明显，移动有时反而表现更好。它适合用户在海外、或对速度要求不苛刻的场景；对大陆访问速度有硬要求的，请回到上一节看香港CN2和国内方案。

**续费会涨价吗？**

促销页标注的年付价同时是长期续费价，这是它区别于很多“首年特价、次年翻倍”商家的一点。
